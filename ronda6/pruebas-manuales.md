# Pruebas manuales pendientes (ronda 6) (las que no se pueden ejecutar desde el entorno de trabajo)

Estado de cada una: **⬜ pendiente** hasta que alguien la ejecute y anote el resultado. Las aproximaciones automáticas están en `LEEME.md`; estas pruebas las sustituyen por la comprobación real.

Preparación general: abrir la web (o la demo pública) en el dispositivo indicado. Para las pruebas con cuenta, usar un email real y la web desplegada con Brevo (la demo no envía emails).
